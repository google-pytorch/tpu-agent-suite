# torch is upper-bounded because torch_tpu loads a per-version glue shim built
# against a specific torch ABI. As of torch_tpu 0.1.1.dev20260922200612, shims
# exist for 2.11/2.12/2.13/2.15 but NOT 2.14, so an unbounded floor resolves to
# 2.14 and fails at import with:
#   ImportError: .../glue_2_13_0/libpywrap_2_13_0_common.so: undefined symbol:
#     torch::autograd::_wrap_outputs(...)
# Bump this bound when torch_tpu ships a shim for a newer torch.
# The torch and jax floors are the versions in lmsysorg/sglang:v0.1.0-tpu.
